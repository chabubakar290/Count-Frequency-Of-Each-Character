Is task me maine character frequency counter ko 3 different methods se implement kiya.

Pehle method me maine plain object use kiya jisme har character aur uski count store ki.
Isme pehle check kiya ke key pehle se mojood hai ya nahi, agar mojood ho to uski value increase ki aur agar nahi ho to uski value 1 se initialize ki.

Doosre method me maine isi problem ko JavaScript Map ki madad se solve kiya jisme has(), get() aur set() methods use kiye.

Teesre method me maine character codes ki array use ki jisme har character ka ASCII code array ke index ke taur par use hua aur uski frequency store ki gayi.

Teeno methods ki time complexity O(n) hai kyun ke ye string ko sirf ek baar scan karte hain.
Performance ke hisaab se array method sab se fast tha, uske baad Map aur phir object method aata hai.
Object method simple aur samajhne me asaan hai.
